# AGENTS.md

`bench` is a Motoko library for benchmarking Motoko code, distributed as a [Mops](https://mops.one) package.

## Layout

- `src/` — the library source (`lib.mo`), published as the `bench` package.
- `test/` — Motoko tests (`*.test.mo`) run by `mops test`.
- `example/` — a self-contained example project with its own `mops.toml`; its benchmarks live in `example/bench/*.bench.mo`.

## Toolchain

This project uses Mops and the DFINITY SDK (`dfx`). Tool versions are pinned:

- `mops.toml` `[toolchain]`: `moc = 1.0.0`, `wasmtime = 40.0.0`.
- CI uses `dfx` version `0.30.1` and Node.js `22`.

Install dependencies with `mops install` before running tests or benchmarks.

## Test

- `mops test` — run the test suite (this is the CI test step).

## Benchmarks

- `mops bench` — run benchmarks. Benchmark files must be named `*.bench.mo` and each must export an `init()` returning a `Bench.Bench`.
- The example's benchmarks run from the `example/` directory: `cd example && mops bench`.

## Conventions

- `.mops/` is generated by Mops (git-ignored); never hand-edit it.
- Running benchmarks starts a local `dfx` replica, so `dfx` must be installed and on `PATH`.
- Packages used only in benchmarks belong in the `[dev-dependencies]` section of `mops.toml`.
