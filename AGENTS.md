# AGENTS.md

A Motoko library (`bench`) for benchmarking Motoko code, distributed via the Mops package manager.

## Prerequisites

- Mops (`mops`) — the Motoko package manager. Dependencies live in `mops.toml`.
- `dfx` — required to run benchmarks (they start a local replica). CI uses dfx `0.30.1`.
- The Motoko compiler (`moc`) is pinned via `mops.toml` under `[toolchain]`. Install/select it with `mops toolchain use moc latest`.

## Build / Test

- Install dependencies: `mops install`
- Run the test suite: `mops test`
- Run the example benchmarks: `cd example && mops bench` (requires a running `dfx`)

CI (`.github/workflows/pull_request_build.yml`) runs `mops test` and, from `./example`, `mops bench`.

## Layout

- `src/` — library source; `src/lib.mo` is the package entry point imported as `mo:bench`.
- `test/` — tests in `*.test.mo` files, run by `mops test`.
- `example/` — a self-contained Mops project with its own `mops.toml`; benchmarks under `example/bench/` as `*.bench.mo` files.

## Conventions

- Benchmark files must be named `*.bench.mo` and export an `init() : Bench.Bench` function (see `README.md`).
- Do not hand-edit the `.mops/` directory; it is generated by `mops install` and gitignored.
- The `moc` and `wasmtime` versions in `[toolchain]` of `mops.toml` are pinned; keep them in sync rather than overriding ad hoc.
