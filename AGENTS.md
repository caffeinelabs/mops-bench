# AGENTS.md

A Motoko library (`bench`, distributed via [Mops](https://mops.one)) for benchmarking Motoko code, producing results as markdown tables.

## Prerequisites

- [Mops](https://mops.one) (install dependencies with `mops install`).
- [dfx](https://internetcomputer.org/docs/building-apps/getting-started/install) — CI uses version `0.30.1`. `mops bench` starts a local dfx replica.
- A `moc` toolchain; CI runs `mops toolchain use moc latest` if one is not present.

## Build, test, bench

- Test: `mops test` (test files live in `test/*.test.mo`).
- Benchmark: `mops bench` (benchmark files are `bench/*.bench.mo`).
- The `example/` package has its own `mops.toml`; run its benchmarks from within it: `cd example && mops bench`.

There is no separate lint or format step configured in this repository.

## Layout

- `src/lib.mo` — the library source (`mo:bench`).
- `test/` — Mops tests.
- `example/` — a standalone example Mops package demonstrating usage; CI runs `mops bench` here.

## Conventions

- Pinned toolchain versions are declared in `mops.toml` under `[toolchain]` (`moc = "1.0.0"`, `wasmtime = "40.0.0"`); keep CI and local tooling consistent with these.
- `.mops/` is generated by Mops and git-ignored; never hand-edit it.
- Benchmark files must be named `*.bench.mo` and export a `public func init() : Bench.Bench`.
- Packages used only in benchmarks/tests belong under `[dev-dependencies]` in `mops.toml`.
