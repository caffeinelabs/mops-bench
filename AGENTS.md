# AGENTS.md

A Motoko library (`bench`) for benchmarking Motoko code, distributed via [Mops](https://mops.one).

## Layout

- `src/` — library source (`lib.mo`, imported as `mo:bench`).
- `test/` — Mops tests (`*.test.mo`).
- `example/` — standalone consumer package with its own `mops.toml`; benchmarks live in `example/bench/*.bench.mo`.

## Build, test, bench

This is a Mops package with no build step. Requires the `mops` CLI and `dfx` installed.

- Test: `mops test`
- Run example benchmarks: `cd example && mops bench` (requires `dfx`, which manages a local replica).
- Ensure the Motoko compiler is available: `mops toolchain use moc latest`

## Conventions & gotchas

- Toolchain versions are pinned in `mops.toml` under `[toolchain]` (`moc = "1.0.0"`, `wasmtime = "40.0.0"`). CI additionally pins `dfx` 0.30.1 and Node.js 22.
- Benchmark files must be named `*.bench.mo` and each must export `init() : Bench.Bench` (see `README.md` for the template).
- `.mops/` is generated by `mops` and git-ignored — never hand-edit it.
- The example package (`example/mops.toml`) is versioned independently of the root package and lists benchmark-only deps under `[dev-dependencies]`.
- CI (`.github/workflows/pull_request_build.yml`) runs `mops test` and the example `mops bench` on pull requests; both must pass.
